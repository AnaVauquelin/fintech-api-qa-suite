# FinTech API QA Suite (Contract, Idempotency & Security)

Automated API quality assurance framework for **FinTech & RegTech** systems.

## What This Suite Validates
1. **Multi-Jurisdiction VAT & Reverse-Charge Rules** (NL, DE, ES, PL, EU B2B)
2. **Strict JSON Schema Contract Enforcement**
3. **Financial Idempotency (`Idempotency-Key`)**
4. **Multi-Tenant Data Isolation (`403 Forbidden` spoofing guard)**
5. **Automated CI/CD Security & Lint Gate (`Ruff` + `Bandit`)**
